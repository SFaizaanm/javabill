About this project

A beginner-friendly Spring Boot project demonstrating Java, JDBC, MySQL, Thymeleaf and responsive Bootstrap layouts.

Tariff values are illustrative sample rates only and do not represent any electricity provider's rates.

  • MySQL persistence through JDBC PreparedStatement
  • Progressive tariff slab calculation
  • Consumer and bill management
  • Responsive Bootstrap 5 interface
