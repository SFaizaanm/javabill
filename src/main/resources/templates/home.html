About Project

This full-stack Java application is designed to simplify electricity billing operations. It combines business logic, database storage, secure validation and a clean interface to help users manage meter reading data and generate payment-ready bills.

Users can input meter readings, view slab-wise calculations, and generate professional bills with print support.

  • MySQL database support
  • JDBC-based CRUD operations
  • Progressive tariff slab logic
  • Responsive UI with Bootstrap 5
